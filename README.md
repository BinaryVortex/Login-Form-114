# Login Form

A clean, responsive login form built with plain HTML, CSS and JavaScript.

![Login Form Preview](./Screenshot%202024-08-25%20153431.png)

## Overview

This small project demonstrates a modern, accessible login UI with client-side validation and subtle animations. It's intended as a learning/example project or a starter UI you can drop into static sites.

## Features

- Responsive layout that works on mobile and desktop
- Client-side form validation (email and password checks)
- Clear visual focus/hover states and simple animations
- Lightweight: no frameworks or build step required (vanilla HTML/CSS/JS)

## Demo

Open `index.html` in your browser to view the form locally, or copy the files into any static host.

## Usage

1. Clone the repo:

   git clone https://github.com/BinaryVortex/Login-Form-114.git

2. Open `index.html` in your browser.

3. Inspect or modify `style.css` and `script.js` to customize behavior and styling.

## File structure

- `index.html` — markup for the login form
- `style.css` — styles and responsive rules
- `script.js` — client-side validation and interactivity
- `Screenshot 2024-08-25 153431.png` — preview image used in this README

## Customize

- Replace the screenshot with your own by updating `Screenshot 2024-08-25 153431.png` or changing the path in this README.
- Hook the form to a backend by handling the submit event in `script.js` (currently client-side only).
